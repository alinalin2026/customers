# customers

Live and in-progress Web99 customer sites.

- `sites/<slug>/` — approved, published builds. This is what `SITES_REPO_*`
  in the dashboard app pushes to for paying customers.
- `leads/<slug>/` — manual pipeline working folder for a lead worked through
  chat: `lead.md` (raw lead + research), `brief.json` (the plan, same shape
  the dashboard analyst produces), `status.md` (where it's at).
